# 发疯得福 · Emotion Paper Ball

**情绪释放 Web App** — 把你的情绪揉成纸团，扔出去。

CSS 3D 折纸动画 + Canvas 破坏动效 + 粒子系统。中国传统文化中「碎碎平安」的数字化表达。

---

## 两种模式

### 嘴替模式
选择或输入想说但不敢说的话，AI 帮你说出来。纸张生成、折叠、飞出的完整动画。

### 暴走模式
在 Canvas 上疯狂滑动，释放情绪。包含：
- 破坏动效（纸张撕裂）
- 粒子系统（情绪碎片）
- 进度条（释放强度）

## 技术实现

- **CSS 3D Transforms**：纸张折叠、翻转、飞行动画
- **Canvas API**：破坏动效 + 粒子系统
- **纯前端**：HTML + CSS + vanilla JavaScript，无框架依赖
- **响应式设计**：移动端优先，PWA 友好

## 快速开始

直接在浏览器中打开 `index.html`，或部署到任意静态托管服务。

```bash
# 本地开发
npx serve .
# 或
python -m http.server
```

## 设计哲学

> 情绪不需要被「管理」，需要被「释放」。
> 中国传统中「碎碎平安」——破坏可以是祝福。

不做又一个冥想 App。做第一个让你理直气壮发疯的产品。
